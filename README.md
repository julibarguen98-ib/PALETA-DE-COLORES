# Paleta de Colores - HTML5 & CSS3

Este proyecto consiste en replicar una paleta de colores utilizando **HTML5** y **CSS3**, organizando los bloques de color en una cuadrícula con un diseño limpio y uniforme.

## Objetivo

Reproducir la imagen de referencia aplicando una distribución ordenada de colores, espaciado consistente y estilos modernos mediante HTML5 y CSS3.

## Tecnologías utilizadas

- HTML5
- CSS3

## Características

- Estructura semántica con HTML5.
- Cuadrícula de bloques de colores.
- Espaciado y bordes redondeados con CSS.
- Diseño adaptable para diferentes tamaños de pantalla.
